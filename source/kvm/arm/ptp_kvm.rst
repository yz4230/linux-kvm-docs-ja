=============================
arm/arm64 の PTP_KVM サポート
=============================

PTP_KVM は、ホストとゲストの間で高精度に時刻を同期するために使う。
KVM 固有のハイパーコールを使って、ホストからゲストへウォールクロックと
カウンタの値を渡す仕組みに依存している。

``ARM_SMCCC_VENDOR_HYP_KVM_PTP_FUNC_ID``
----------------------------------------

特定のカウンタの現在時刻情報を取得する。エンディアンの制限はない。

+-------------------+----------+----+------------------------------------------------+
| 存在:             | 任意                                                           |
+-------------------+----------+----+------------------------------------------------+
| 呼び出し規約:     | HVC32                                                          |
+-------------------+----------+----+------------------------------------------------+
| ファンクション ID:| (uint32) | 0x86000001                                          |
+-------------------+----------+----+------------------------------------------------+
| 引数:             | (uint32) | R1 | ``KVM_PTP_VIRT_COUNTER (0)``                   |
|                   |          |    +------------------------------------------------+
|                   |          |    | ``KVM_PTP_PHYS_COUNTER (1)``                   |
+-------------------+----------+----+------------------------------------------------+
| 戻り値:           | (int32)  | R0 | エラー時は ``NOT_SUPPORTED (-1)``、            |
|                   |          |    | それ以外はウォールクロック時刻の上位 32 ビット |
|                   +----------+----+------------------------------------------------+
|                   | (uint32) | R1 | ウォールクロック時刻の下位 32 ビット           |
|                   +----------+----+------------------------------------------------+
|                   | (uint32) | R2 | カウンタの上位 32 ビット                       |
|                   +----------+----+------------------------------------------------+
|                   | (uint32) | R3 | カウンタの下位 32 ビット                       |
+-------------------+----------+----+------------------------------------------------+
